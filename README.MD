- [Chính sách quyền riêng tư](index.html).

Thời hạn xử lý yêu cầu xóa: **tối đa 7 ngày**.

## Xuất bản bằng GitHub Pages

1. Commit và push các thay đổi lên nhánh `main`.
2. Mở **Settings → Pages** trên GitHub.
3. Chọn **Deploy from a branch → main → / (root) → Save**.
4. Bật **Enforce HTTPS** khi tùy chọn hiển thị.
5. Mở hai URL bên dưới, kiểm tra nội dung mới và nút gửi email.
